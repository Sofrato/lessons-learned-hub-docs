# Release notes

## Documentation baseline — 14 November 2026

This is the first documentation package, prepared against the current application source. It is **not** an announcement that a production version has shipped or received Marketplace approval. The source package identifies itself as 0.1.0; this does not establish the version installed on a customer's site.

The documented features are:

- Shared project registry and Add Lessons / Use Lessons macros.
- Lesson creation, completeness, editing, and logical deletion.
- Context-based Discover suggestions and project watchlists.
- Hub Lessons, Statistics, and Data Quality views.
- Source-page and project-home-page rules for write permissions.
