# Lessons Learned Hub

User documentation for Lessons Learned Hub, an app for **Confluence Cloud** by Sofrato.

Capture lessons from your projects, discover relevant experience from other teams, and track how your project acts on it.

> **Before you start:** lessons are shared across the Confluence site where the app is installed. Restricting a source page does not make its lessons private. Read [Permissions and visibility](permissions.md) before adding information.

## How the app fits together

1. **Add Lessons** is a macro on a Confluence page. Use it to capture lessons for a project.
2. **Use Lessons** is a macro for a project. Its **Discover** tab suggests lessons from other projects; its **Watchlist** tab tracks the lessons your project wants to act on.
3. **Lessons Learned Hub** is the site-wide app view. It contains **Lessons**, **Statistics**, and **Data Quality**.

A project can be linked to macros on several pages. Those macros share the same project data. A project in this app is an entry in its project registry; it is not a Confluence space or a Jira project.
